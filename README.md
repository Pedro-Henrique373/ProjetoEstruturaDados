# Projeto de Estrutura de Dados com Python, feito no curso de Analise de Sistemas (ADS)
O projeto foi feito com a IDE Pycharm, utilizando a linguagem de programaçaõ Python, feito no curso de Analise e Desenvolvimento de Sistemas (ADS) na universidade Uninter, que consiste em treino para se familiarizar com estruturas de dados, criando uma lógica de aplicação para implemetação de listas encadeadas simples, e para funções Hash.
## Tecnologias utilizadas:
-Pycharm\
-Linguagem Python\
-Estruturas de dados\
-Paradigma orientado a objetos (POO)
